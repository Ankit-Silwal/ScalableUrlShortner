# Million-link benchmark: 2026-09-29

Measured at 2026-09-29T17:31:49.244Z against the scaling application in commit 33e5bfb. The harness and raw results are committed alongside this report.

## Setup

- Dataset: 1,000,000 actual PostgreSQL rows.
- API: 2 independent Node.js processes; worker: 1 process.
- PostgreSQL 18 and Redis 7.4 in Docker; clients talk directly to API ports in round-robin order.
- Node v24.11.0 on win32; AMD Ryzen 7 7445HS w/ Radeon 740M Graphics; 12 logical CPUs; 15.3 GiB system memory.
- 32 concurrent HTTP/1.1 keep-alive clients per phase, 15 seconds per phase. A 3-second warmup used 8 clients.
- Dataset/index size after seeding: 211.6 MiB; seeding plus ANALYZE: 6.74 seconds. This synthetic dataset uses short example.com URLs and is not a general storage estimate.
- Shared rate limits and analytics remained enabled; the request limit was raised for the benchmark.

## Results

| Traffic pattern | Requests | Redirects/sec | p95 ms | p99 ms | Transport/non-302 errors |
| --- | ---: | ---: | ---: | ---: | ---: |
| hot-link | 59,054 | 3,935.24 | 11.27 | 14.52 | 0 |
| mixed-80-percent-hot | 48,473 | 3,229.65 | 16.06 | 21.09 | 0 |
| uniform-million-links | 41,995 | 2,798 | 16.06 | 19.30 | 0 |

The uniform phase sampled codes spread across the million-row dataset; it did not request every stored code. The mixed phase sent 80% to a 100-code hot set and 20% across the full dataset.

Including warmup, all 154,952 successful redirects were reflected in PostgreSQL: 154,952 applied clicks. Workers committed 2,400 nonempty batches. Final drain/check time was 1.39 seconds. Cache metrics recorded 111,578 hits and 43,374 misses.

The saved EXPLAIN ANALYZE plans show a primary-key index scan for code lookup and the active composite index for a cursor near 90% of the dataset. Point-lookup execution time was 0.041 ms; cursor-page execution time was 0.056 ms in these single samples.

## Additional checks

The separate Docker smoke test exercised Nginx, three API replicas, and two workers: all 90 initial clicks were applied, redirects continued after one API replica stopped, and deletion stopped subsequent redirects. Unit/integration tests cover cache expiry, shared limits, replay after commit, transaction rollback, competing workers, bounded queues, and precise pagination.

## What this proves and does not prove

This verifies a million-row schema, indexed access, and short-run throughput above the average and illustrative bursts for millions of daily redirects. One million redirects/day averages 11.6 requests/sec; ten million averages 115.7. Do not multiply a 15-second peak rate by 86,400 and call it measured daily capacity.

The load generator is closed-loop. All services share one laptop, and database pages are warm after seeding. The timed path excludes Nginx/TLS; test Redis has persistence disabled. The sample deployment enables Redis AOF and was functionally tested, but it was not used for these throughput figures. URL length, cache hit rate, hot-key distribution, hardware, network latency, persistence, cold-start behavior, client burst shape, and hosted database limits can change the results substantially. Run an arrival-rate load test and long soak with production infrastructure before setting an SLA.
